# DOODLE MOVIES
**Doodle Movies** App doesn't store any media files on our servers and is not directly linked to the media. Third-party services host all media, and Doodle App merely provides a search and web scraping tool that indexes publicly available data. We are not responsible for the content or availability of the media, as we do not host or control any of it.

### Project Description
**Doodle Movies** is an app for streaming movies from multiple providers so that you can easily access all kinda movies and animes in one app.

### The Problem (that doesn't exist)
Most people purchase different platforms to watch movies and anime, yet many still face issues with limited availability of content. In our case, we do not charge any membership fees, nor do we collect any personal or private data from users. There is no limit on accessing new movies, and users do not need multiple websites or platforms. All content is available on a single platform.

### The Solution (that nobody asked for)
We collect content from various free movie websites and integrate their servers into a single application through APIs. This allows users to access all available free movies conveniently from one app.
